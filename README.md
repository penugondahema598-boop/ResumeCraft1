# ResumeCraft

A static resume-builder website built with HTML, CSS and JavaScript.

## Run locally
1. Keep `index.html`, `style.css`, `script.js`, and `templates.js` in the same folder.
2. Open `index.html` in a modern browser.

## Features
- 24 sample templates across ATS, Modern, Creative, Student and Professional categories.
- Live template switching from the gallery and builder dropdown.
- Live accent colour picker and preset colour swatches.
- Live resume content preview.
- Browser-local draft saving.
- Print / Save as PDF using the browser print dialog.
- Responsive layout for mobile and desktop.

## Publish with GitHub Pages
1. Create/open a GitHub repository.
2. Upload all five files to the repository root (not inside an extra nested folder).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear and open it.
7. Test template selection, colour changes, and PDF printing on the published URL.

## Important
This is a front-end starter website. It is not yet a commercial SaaS product: no backend, login, cloud sync, AI writing, payment processing, or secure paid-template access is included. The 24 included designs use distinct layout families and styling variations; they are not 24 fully bespoke page compositions yet.
